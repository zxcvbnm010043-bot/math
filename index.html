如何部署此測驗 App 到 GitHub Pages

  1. 準備檔案：將此頁面的程式碼儲存為名為 index.html 的單一檔案。
  2. 建立 Repository：登入 GitHub 點擊 New Repository，設定名稱（例：math-quiz）並保持公開（Public）。
  3. 上傳檔案：點擊 Upload an existing file，將 index.html 上傳並點擊 Commit。
  4. 開啟 GitHub Pages：進入專案頁面頁頂的 Settings -> 左側選單 Pages。
  5. 選擇分支發布：在 Branch 選項中選擇 main（或 master）分支並點擊 Save。
  6. 發布成功：稍等 1-2 分鐘後重新整理，即可取得你的專屬網址！
