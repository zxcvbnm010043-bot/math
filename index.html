GitHub Pages 免費部署教學

遵循以下簡短步驟，即可將本網頁發布為個人專屬的免費線上測驗網站：

  1. 建立 Repository： 登入 GitHub，點擊右上角「+」選取 New repository。
  2. 命名專案： 輸入專案名稱 (例如 math-quiz-app)，勾選 Public，並點擊 Create。
  3. 上傳 HTML： 在儲存庫頁面點選 Upload an existing file，將這個 index.html 檔案拖曳上傳並 Commit。
  4. 啟用 Pages： 進入專案的 Settings → 左側選單選取 Pages。
  5. 發布分支： 在 Build and deployment Source 中選擇 Deploy from a branch，Branch 選取 main / root 後按下 Save。
等待 1-2 分鐘重新整理，即可在提供的 GitHub URL 直接免費存取您的數學測驗網頁！
